# 연구 심화·품질 향상 계획 (2026-07-30)

논문(`paper/apiems2026_draft.md`, 국문 `paper/thesis_ko.md`)을 처음부터 끝까지
정독한 뒤, 현재 원고의 강점·약점을 진단하고 품질을 한 단계 올리기 위한 실행
계획을 정리한다. 지도교수 지침(새 문제축 추가 금지, RL 고도화 금지, optimal
용어 규율)을 전제로 하며, **"프레이밍 다듬기 대신 실험·검증 보강"** 원칙을
따른다.

## 0. 현재 원고 진단

### 강점 (유지할 것)
- **진짜 신규성**: 컴파운드 트럭에 도착 시간창·소프트 마감 최초 도입.
- **강한 방법**: VAA-GILS가 정확해 기준 존재 셀에서 CP-SAT 인컴번트에 필적
  (0.1~0.6%), 증명 셀에서 최적 일치, 70~700× 고속.
- **엄밀한 분해**: B1(연산자 풀)·B2(컴포넌트)·K1(선택 정책)·C3(λ) 4종 ablation.
- **정직성**: 증명 셀에만 optimal, 느슨한 하한(171~273%)을 한계로 명시, RL을
  negative finding으로 정직 서술, C3를 tuning 풀에서만 수행.
- **재현 프로토콜**: train/tuning/test 시드 3분할, 방법·하이퍼파라미터 동결.

### 리뷰어가 찌를 약점 (보강 대상)
1. **TW 셀에 GILS 외 baseline 부재.** `Paper-SA-RL5`는 `none` 셀에서만 실행
   (`experiments/k1_run.py:53`, `if tw is None`). 시간창 셀에서는 자기 ablation
   끼리만 비교 → "외부 경쟁자 대비 우위"가 TW에서 공백. **가장 시급.**
2. **통계력.** 셀당 인스턴스 5개. Wilcoxon n이 셀별로 작음 → 20개로 확장 필요
   (D1, thesis_plan에 이미 있음).
3. **단일 flow pattern.** 실험은 `uniform`만 사용(생성기는 skewed/clustered도
   지원). 화물 분포에 대한 강건성 미검증.
4. **하한이 느슨.** TW 셀 171~273% → 그 셀들에서 near-optimal 주장 불가,
   best-known에만 의존.
5. **정확해 커버리지 얕음.** M/L은 셀당 2 인스턴스만 CP-SAT. best-known 영역이
   넓어 "정확해 검증"의 폭이 제한적.
6. **§7 조건이 정성적.** "학습이 언제 효과를 내는가"의 4조건이 추측(conjecture)
   수준 — 실증이 없으면 방법론적 기여의 설득력이 약함.
7. **경쟁 구현 미완.** `crossdock_solver/alns/`에 부분 ALNS(critical_door_destroy,
   regret_k_repair)가 있으나 METHOD_REGISTRY 미연결 → Li et al. 2025 Q-ALNS
   경쟁 baseline이 미완성.

## 1. Tier 1 — 필수·저위험 (동결 범위 내, 2~3주)

리뷰 통과의 하한선. 새 주장 없이 기존 주장의 통계적·비교적 근거만 강화.

### T1-1. TW-공정 baseline (D2) — **최우선**
- **무엇**: `Paper-SA-RL5`에 `tardiness_weight=1.0`을 주입한 메서드를
  METHOD_REGISTRY에 등록하고(필드는 `paper_sa_rl.py:41`에 이미 존재), TW 셀
  (medium/tight)에서 실행. λ=0이면 기존 동작 보존됨을 회귀로 확인.
- **산출**: Table 1의 medium/tight 행에 Paper-SA-RL5 baseline 채움 → 모든 셀
  에서 GILS < Paper-SA-RL5 < VAA 서열 완성.
- **효과/노력**: 약점 #1 직접 해소 / 소(小). 코드 몇 줄 + 재실행.

### T1-2. 셀당 인스턴스 5→20 (D1)
- **무엇**: `experiments/k1_run.py`의 `INDICES`를 0..19로 확장, 백그라운드 실행.
  test 풀은 방법·하이퍼파라미터 동결 상태에서만 touch(현재 동결 유지).
- **산출**: Table 1/2/3/4의 Wilcoxon n 4배 → 결론의 통계적 안정성.
- **효과/노력**: 약점 #2 / 중(中, 장시간 실행). CP-SAT는 시간 예산상 인스턴스
  수를 별도로(예: M/L 셀당 4~6개) 관리.
- **주의**: 20개로도 표의 정성적 결론(단조·유의·무방향전환)이 유지되는지 확인.
  뒤집히면 정직하게 재서술.

### T1-3. Flow-pattern 강건성
- **무엇**: 대표 셀(예: M-medium, L-tight)에서 `skewed`·`clustered` 반복 실행
  → GILS 우위와 RL negative finding이 분포 불변인지 확인.
- **산출**: 부록 표 1장 "flow-pattern robustness".
- **효과/노력**: 약점 #3 / 소~중.

### T1-4. 재현성 패키지
- **무엇**: README에 실행 절차·시드·환경 고정(현재 numpy 2.x ABI로 matplotlib
  불가 → 그림은 `experiments/make_figures.py` 무의존 SVG로 대체됨을 명시).
  코드·인스턴스 생성기·시드 프로토콜을 공개 저장소로.
- **효과/노력**: 채택 확률·인용 / 소.

## 2. Tier 2 — 품질 도약 (동결 범위 내, +2~4주)

기여의 "폭"과 "깊이"를 올림. 리뷰어의 "그래서 SOTA 대비?" 질문 방어.

### T2-1. Q-ALNS 경쟁 baseline 완성 (P3)
- **무엇**: `crossdock_solver/alns/`의 부분 구현을 완성해 Li et al. 2025 [6]의
  Q-learning ALNS를 본 문제에 이식, METHOD_REGISTRY 등록 후 전 셀 비교.
  (도어 수준 유연성은 본 문제에 없으므로 destroy/repair·선택만 이식, 구조
  차이는 명시.)
- **산출**: Table 1에 외부 SOTA 경쟁자 열 추가 → "GILS가 원 모델뿐 아니라
  최신 학습형 ALNS도 능가/대등" 주장.
- **효과/노력**: 신뢰도 큼 / 중~대. **가장 임팩트 큰 baseline 작업.**

### T2-2. 하한 강화 + 정확해 커버리지 확대
- **무엇**: (a) 조합 하한 개선 — TW 셀용 release-aware critical-chain, 도어
  면적에 셋업(DE/DL) 반영, 또는 LP 완화/라그랑지안 하한. (b) M/L에서 CP-SAT
  시간·인스턴스 확대(예: 1800s, 셀당 4개)로 near-optimal 비교 셀 확장.
- **산출**: 약점 #4·#5 완화 → near-optimal 주장 범위 확대, best-known 의존
  축소.
- **효과/노력**: 중~대. 하한은 난이도 있으나 성공 시 논문 격 상승.

### T2-3. 엔진 하이퍼파라미터 강건성
- **무엇**: `restart_after`, `cooling_rate`, `initial_temperature`, `restart_kick`
  민감도 스윕(tuning 풀). 결과가 특정 튜닝값에 과적합이 아님을 입증.
- **산출**: 부록 민감도 표/그림 → "우리 결론은 하이퍼파라미터 우연이 아니다".
- **효과/노력**: 소~중.

## 3. Tier 3 — 격상 (venue를 SCIE급으로 올릴 때, 선택)

지도교수 지침(RL 봉인, 새 축 금지)과 충돌하지 않는 선에서, §7의 방법론적
기여를 추측에서 실증으로 전환.

### T3-1. §7 조건의 실증 — "언제 학습이 되살아나는가" (권장)
- **무엇**: 4조건(저렴한 평가/정적/포화 예산/강한 LS) 중 **하나만** 부정하는
  통제 실험으로, 학습 기반 선택이 균등을 이기는 구간을 *구성적으로* 보임.
  예: (i) 평가에 인위적 지연/비용을 주입 → 나쁜 제안이 비싸질 때 학습이
  이득을 내는지, (ii) 예산을 포화 이전으로 축소(초저예산)했을 때, (iii)
  descent를 약화(1st-improvement/부분 이웃)했을 때. **RL을 개선하는 게 아니라
  조건을 바꿔 기존 selector의 상대 성능이 뒤집히는 지점을 찾는 것** → 지침의
  "RL 고도화 금지"와 무관(방법론 실증).
- **산출**: §7을 "conjecture"에서 "controlled evidence"로 승격 → 논문의 가장
  차별적 기여. negative finding이 조건부임을 *양방향으로* 입증.
- **효과/노력**: 임팩트 최대 / 중~대. **Tier 3의 핵심 추천.**

### T3-2. 실데이터/준실데이터 사례 연구
- **무엇**: 공개 LTL/크로스도킹 데이터 또는 산업 파트너 데이터로 1~2 인스턴스
  케이스 스터디 → 외적 타당성.
- **효과/노력**: 외적 타당성 큼 / 대(데이터 확보 의존).

### T3-3. 경량 이론
- **무엇**: "강한 결정론적 descent가 selection 학습을 무효화한다"를 attractor
  basin/흡수 논증으로 준형식화(정리 1개 수준). §6.2의 "240s CP-SAT 인컴번트
  정확 일치" 관찰을 이론적 직관으로 뒷받침.
- **효과/노력**: 격 상승 / 중(정형화 리스크).

## 4. 실행 순서 제안

```
1주차: T1-1(TW baseline) → 즉시 Table 1 공백 해소
      + T1-2(20-instance) 백그라운드 착수
2주차: T1-3(flow) + T2-3(하이퍼파라미터 강건성)
3~4주차: T2-1(Q-ALNS 경쟁자) — 가장 무거운 baseline
병행/후속: T2-2(하한), T3-1(§7 실증) — venue 목표에 따라 취사
마감 전: T1-4(재현성) + 전 표/그림 최종 동기화
```

**의사결정 게이트**: 목표 매체가 국내 학회지(KCI)면 Tier 1 + T2-1로 충분.
SCIE를 노리면 T2-2와 T3-1(§7 실증)이 사실상 필수 — 이 둘이 "방법론적 기여"를
심사에서 살린다.

## 5. 하지 말 것 (지침 재확인)
- 동적 도착 등 **새 문제축 추가 금지** → future work.
- **RL 성능 개선 투자 금지**. 단, T3-1처럼 *조건을 바꿔 selector 상대성능을
  뒤집는 방법론적 실증*은 "RL 고도화"가 아니라 negative finding의 정밀화이므로
  허용 범위로 판단(지도교수 확인 권장).
- 증명 셀 외 `optimal` 사용 금지(현재 위반 없음, 유지).
